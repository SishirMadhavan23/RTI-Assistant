# RTI Assistant

## Goal
Help citizens generate RTI applications easily.

## User Stories

### Story 1
As a citizen, I want to select a government department so that my RTI reaches the correct office.

### Story 2
As a citizen, I want AI assistance in drafting RTI applications.

## Requirements

- User can select department
- User can enter RTI details
- System generates RTI draft
- User can download the RTI application
